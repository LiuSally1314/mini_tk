# 自动化配置 Action 文档

本文档基于项目中的 YAML 流程配置与 `core/actions.py` 的实现，整理所有可用的 `action` 类型、字段说明与使用示例。

---

## 一、配置文件结构总览

```
config/
├── config.yaml              # 主配置（设备、输出、默认值、激活流程）
└── flows/                   # 流程目录，每个 yaml 文件 = 一个流程
    ├── 将领技能升级.yaml
    ├── 将领技能精工.yaml
    ├── 将领技能强化.yaml
    ├── 将领技能精工强化.yaml
    └── ...
```

### 主配置 `config.yaml`

```yaml
device:
  uri: "Android:///192.168.31.33:40881"

output:
  json_filename: "ocr_result.json"
  query_json_filename: "query_result.json"
  base_dir: "截屏"

defaults:
  ocr_retry: 3          # OCR 重试次数
  retry_interval: 1.0   # 重试间隔（秒）
  click_interval: 0.5   # 点击间隔（秒）
  exact: true           # 是否精确匹配
  sleep: 0.1            # 通用休眠
  enabled: true         # 步骤是否启用

active_flow: "将领技能升级"   # 当前激活的流程名
flows_dir: "config/flows"     # 流程目录
```

### 流程文件结构

```yaml
loop_count: 1        # 整个流程循环次数（可选，默认 1）
steps:               # 步骤列表
  - action: xxx
    ...
```

## 二、通用字段（所有 action 可用）

| 字段 | 类型 | 说明 |
|------|------|------|
| `action` | string | **必填**，动作类型 |
| `remark` | string | 备注，执行时打印 |
| `enabled` | bool | 是否启用，默认取 `defaults.enabled` |
| `sleep` | float | 本步骤执行后休眠秒数 |
| `optional` | bool | 失败时是否跳过继续（部分动作支持） |
| `exact` | bool | OCR 是否精确匹配，默认取 `defaults.exact` |
| `ocr_retry` | int | OCR 重试次数 |
| `retry_interval` | float | 重试间隔 |
| `region` | [x1,y1,x2,y2] | 限定 OCR 查找区域 |
| `coords` | [x,y] | 坐标，配合 `region_size` 可自动生成区域 |
| `region_size` | int | 以 coords 为中心的方形区域边长 |
| `region_w` / `region_h` | int | 以 coords 为中心的矩形区域宽高 |
| `page_keyword` / `confirm_keyword` | string \| list \| dict | 页面确认关键词 |

### 关键词配置三种写法

```yaml
# 1. 字符串：包含即匹配
confirm_keyword: "技能升级"

# 2. 列表：任一匹配
confirm_keyword: ["技能升级", "升级"]

# 3. 字典：高级规则
confirm_keyword:
  mode: "mixed"          # and / or / mixed
  match_mode: "all"      # mixed 时：all / any
  rules:
    - type: "must"       # must / any / not
      keywords: ["最高等级"]
    - type: "not"
      keywords: ["确定"]
```

## 三、Action 详解

### 1. `find` — 查找文本

在页面 OCR 结果中查找目标文本，记录坐标到 `last_coord`。

| 字段 | 说明 |
|------|------|
| `text` | 要查找的目标文本 |
| `page_keyword` / `confirm_keyword` | 页面确认关键词（字符串时与 text 一起查找） |
| `exact` | 是否精确匹配 |
| `region` / `coords` + `region_size` | 限定查找区域 |
| `optional` | 未找到时是否跳过 |

```yaml
- action: find
  remark: "查找进阶按钮"
  text: "进阶"
  exact: false
  coords: [540, 2277]
  region_size: 300
  ocr_retry: 4
  retry_interval: 0.2
  optional: true
```

---

### 2. `click` — 点击

| 字段 | 说明 |
|------|------|
| `target` | `last` / `skill`（用上次 find 坐标）或 `coords`（用 coords 字段） |
| `coords` | 坐标 `[x, y]` |
| `times` | 点击次数，默认 1 |
| `interval` / `click_interval` | 多次点击间隔 |
| `page_keyword` | 点击前页面确认 |

```yaml
- action: click
  remark: "点技能框"
  target: skill          # 使用 for_each_skill / repeat_skill 传入的坐标
  times: 1
  sleep: 0.3

- action: click
  remark: "升级"
  target: coords
  coords: [531, 1775]
  times: 2
  interval: 0.2
```

---

### 3. `find_click` — 查找并点击

先 `find` 再 `click`。若 `target: coords` 则点击固定坐标；否则点击 find 到的坐标。

```yaml
- action: find_click
  remark: "等进阶出现并点击"
  text: "进阶"
  exact: false
  coords: [540, 2277]
  region_size: 300
  ocr_retry: 4
  retry_interval: 0.2
  optional: true
```

---

### 4. `wait` — 等待

| 字段 | 说明 |
|------|------|
| `seconds` | 等待秒数（**必填**） |

等待期间会持续检查异步 abort。

```yaml
- action: wait
  seconds: 1.0
```

---

### 5. `wait_ocr` — 等待文本出现

轮询 OCR 直到目标文本出现。

| 字段 | 说明 |
|------|------|
| `text` | 等待的文本（**必填**） |
| `exact` | 是否精确匹配 |
| `ocr_retry` | 重试次数 |
| `retry_interval` | 重试间隔 |
| `region` | 限定区域 |
| `optional` | 超时是否跳过 |

```yaml
- action: wait_ocr
  text: "升级成功"
  ocr_retry: 5
  retry_interval: 0.5
  optional: true
```

---

### 6. `abort_check` — 终止检查（核心）

支持**同步**和**异步**两种模式，用于检测满级、弹窗消失等中断条件。

| 字段 | 说明 |
|------|------|
| `abort_text` | 终止判断规则（字符串/列表/字典） |
| `on_match` | 命中走向：`abort_skill` / `abort_loop` / `next` |
| `on_miss` | 未命中走向：`next` / `abort_skill` / `abort_loop` |
| `async` | 是否异步监听（默认 false） |
| `consume_at` | 异步消费时机：`step` / `loop_end` / `skill_end` |
| `not_confirm_count` | not 规则连续命中确认次数（默认 3） |
| `ocr_retry` | 同步模式重试次数 |
| `retry_interval` | 重试间隔 |

#### 走向说明

- `abort_skill`：抛出 `SkillAbort`，被 `for_each_skill` / `repeat_skill` 捕获，跳到下一个技能
- `abort_loop`：抛出 `LoopBreak`，被 `repeat` 捕获，跳出当前 repeat
- `next`：继续下一步

#### 同步示例（检查是否满级）

```yaml
- action: abort_check
  remark: "检查技能是否已满级"
  abort_text:
    mode: "mixed"
    rules:
      - type: "must"
        keywords: ["最高等级"]
  on_match: abort_skill
  on_miss: next
  ocr_retry: 1
  retry_interval: 0.3
```

#### 异步示例（循环内监听打断）

```yaml
- action: abort_check
  remark: "异步监听是否已满级"
  async: true
  abort_text:
    mode: "mixed"
    rules:
      - type: "must"
        keywords: ["最高等级"]
  on_match: abort_skill
  consume_at: "loop_end"
  retry_interval: 0.3
```

---

### 7. `repeat` — 内循环

| 字段 | 说明 |
|------|------|
| `times` | 循环次数（**必填**） |
| `steps` | 子步骤列表（**必填**） |

子步骤可被 `LoopBreak` 打断（由内部 `abort_check` 的 `abort_loop` 触发）。

```yaml
- action: repeat
  times: 7
  steps:
    - action: click
      target: coords
      coords: [849, 2282]
      times: 1
      sleep: 0.5
    - action: click
      target: coords
      coords: [500, 1682]
      times: 1
      sleep: 0.5
```

---

### 8. `for_each_skill` — 遍历技能

对每个技能坐标点击一次，然后执行子步骤。支持 `SkillAbort` 中止当前技能跳到下一个。

| 字段 | 说明 |
|------|------|
| `skill_coords` | 技能坐标列表（**必填**） |
| `sub_steps` | 每个技能的子步骤（**必填**） |
| `click_wait` | 点击技能后等待秒数 |
| `global_abort` | 全局终止关键词 `{keywords: [...], exact: bool}` |

```yaml
- action: for_each_skill
  remark: "对技能1~6依次执行"
  click_wait: 0.5
  skill_coords:
    - [294, 895]
    - [540, 895]
    - [798, 911]
  global_abort:
    keywords: ["网络异常"]
    exact: false
  sub_steps:
    - action: abort_check
      abort_text:
        mode: "mixed"
        rules:
          - type: "must"
            keywords: ["最高等级"]
      on_match: abort_skill
      on_miss: next
      ocr_retry: 1
      retry_interval: 0.3
```

---

### 9. `repeat_skill` — 技能重复循环

对每个技能点击后，重复执行子步骤 N 次。

| 字段 | 说明 |
|------|------|
| `skill_coords` | 技能坐标列表（**必填**），元素可为 `[x,y]` 或 `{coord: [x,y], loop_times: N}` |
| `sub_steps` | 每轮子步骤（**必填**） |
| `loop_times` | 每技能循环次数（默认 25） |
| `click_wait` | 点击技能后等待 |
| `loop_interval` | 每轮间隔 |
| `close_popup_before_next` | 换技能前是否按返回键 |
| `abort_text` / `on_match` / `not_confirm_count` | 异步终止配置 |

```yaml
- action: repeat_skill
  remark: "对4个技能依次升级，每个技能循环25次"
  skill_coords:
    - [389, 1328]
    - [895, 1313]
  click_wait: 0.5
  loop_times: 25
  loop_interval: 0.3
  close_popup_before_next: false
  sub_steps:
    - action: click
      remark: "点技能框"
      target: skill
      times: 1
      sleep: 0.3
    - action: click
      remark: "升级"
      target: coords
      coords: [531, 1775]
      times: 2
      interval: 0.2
```

---

### 10. `loop_skills` — 自动定位技能并轮询升级

使用 `SkillUpgrader` 自动根据页面文本（`常规技能` → `功勋技能`）定位 2×2 技能区域坐标并轮询升级。

| 字段 | 说明 |
|------|------|
| `section_start` | 区域起点文本，默认 `常规技能` |
| `section_end` | 区域终点文本，默认 `功勋技能` |
| `popup_keyword` | 弹窗关键词，默认 `技能升级` |
| `upgrade_keyword` | 升级按钮文本，默认 `升级` |
| `offset_range` | 坐标偏移上限，默认 30 |
| `max_rounds_per_skill` | 每技能最大轮询次数，默认 20 |
| `wait_between` | 技能间等待，默认 1.0 |
| `max_skills` | 最大技能数，默认 24 |

```yaml
- action: loop_skills
  section_start: "常规技能"
  section_end: "功勋技能"
  popup_keyword: "技能升级"
  upgrade_keyword: "升级"
  max_rounds_per_skill: 20
```

---

### 11. `include_flow` — 引用子流程

| 字段 | 说明 |
|------|------|
| `flow` | 子流程名（**必填**，对应 flows/ 下文件名） |
| `before` | 进入子流程前的步骤列表 |
| `after` | 子流程结束后的步骤列表 |
| `loop_count` | 覆盖子流程循环次数 |

自动检测循环引用并报错。

```yaml
- action: include_flow
  flow: 将领技能强化
  before:
    - action: click
      remark: "进入技能强化"
      text: "强化"
      target: coords
      coords: [278, 355]
      times: 1
      sleep: 0.5
  after:
    - action: wait
      seconds: 1.0
```

---

### 12. `debug_ocr` — 调试 OCR

打印当前页面所有 OCR 文本及坐标，用于调试。

```yaml
- action: debug_ocr
```

## 四、Action 速查表

| Action | 用途 | 关键字段 |
|--------|------|----------|
| `find` | 查找文本 | `text`, `exact`, `region` |
| `click` | 点击 | `target`, `coords`, `times` |
| `find_click` | 查找并点击 | `text`, `target`, `coords` |
| `wait` | 等待 | `seconds` |
| `wait_ocr` | 等待文本出现 | `text`, `ocr_retry` |
| `abort_check` | 终止检查 | `abort_text`, `on_match`, `async` |
| `repeat` | 内循环 | `times`, `steps` |
| `for_each_skill` | 遍历技能 | `skill_coords`, `sub_steps` |
| `repeat_skill` | 技能重复循环 | `skill_coords`, `loop_times`, `sub_steps` |
| `loop_skills` | 自动定位技能升级 | `section_start`, `section_end` |
| `include_flow` | 引用子流程 | `flow`, `before`, `after` |
| `debug_ocr` | 调试 OCR | 无 |

## 五、控制流与异常机制

```
SkillAbort  → for_each_skill / repeat_skill 捕获 → 跳到下一个技能
LoopBreak   → repeat 捕获 → 跳出当前 repeat
UserExit    → main 捕获 → 程序退出
```

### 异步 abort_check 生命周期

```
repeat_skill / for_each_skill 开始
    ↓
启动异步监听线程（若配置相同则复用）
    ↓
每轮循环 check_async_hit(phase="step")
    ↓
循环结束 check_async_hit(phase="loop_end")
    ↓
技能结束 check_async_hit(phase="skill_end")
    ↓
stop_async() 停止线程
```

### `consume_at` 语义

| 值 | 消费时机 |
|----|----------|
| `step` | 每步检查时立即消费 |
| `loop_end` | 仅在 repeat 每轮结束时消费 |
| `skill_end` | 仅在技能结束时消费 |

## 六、完整流程示例

### 示例 1：将领技能升级

```yaml
loop_count: 1
steps:
  - action: repeat_skill
    remark: "对4个技能依次升级，每个技能循环25次"
    skill_coords:
      - [389, 1328]
      - [895, 1313]
      - [375, 1500]
      - [893, 1495]
    click_wait: 0.5
    loop_times: 25
    loop_interval: 0.3
    close_popup_before_next: false
    sub_steps:
      - action: click
        target: skill
        times: 1
        sleep: 0.3
      - action: click
        target: coords
        coords: [531, 1775]
        times: 2
        interval: 0.2
      - action: click
        target: coords
        coords: [770, 1764]
        times: 2
        interval: 0.2
```

### 示例 2：技能精工（含异步打断）

```yaml
loop_count: 1
steps:
  - action: for_each_skill
    click_wait: 0.5
    skill_coords:
      - [294, 895]
      - [540, 895]
      - [798, 911]
    sub_steps:
      - action: abort_check
        remark: "检查技能是否已满级"
        abort_text:
          mode: "mixed"
          rules:
            - type: "must"
              keywords: ["最高等级"]
        on_match: abort_skill
        on_miss: next
        ocr_retry: 1
        retry_interval: 0.3

      - action: repeat
        times: 7
        steps:
          - action: click
            target: coords
            coords: [849, 2282]
            times: 1
            sleep: 0.5

          - action: abort_check
            async: true
            abort_text:
              mode: "mixed"
              match_mode: "any"
              rules:
                - type: "must"
                  keywords: ["最高等级"]
                - type: "not"
                  keywords: ["确定"]
            on_match: abort_skill
            consume_at: "loop_end"
            retry_interval: 0.3

          - action: click
            target: coords
            coords: [500, 1682]
            times: 1
            sleep: 0.5
```

## 七、最佳实践

1. **技能坐标配置**：`for_each_skill` / `repeat_skill` 的 `skill_coords` 顺序即执行顺序，建议按 UI 从上到下、从左到右。
2. **异步 abort_check 复用**：相同签名（abort_text + interval + region + on_match + consume_at + not_confirm_count）的异步监听会自动复用线程，避免 repeat 内每轮重启导致计数重置。
3. **not 规则连续确认**：`not_confirm_count` 用于避免 OCR 瞬时误判，默认 3 次。
4. **失败处理**：`optional: true` 让步骤失败时继续执行；否则流程会跳过本循环剩余步骤。
5. **调试**：用 `debug_ocr` 打印当前页面所有 OCR 文本定位问题。
6. **子流程复用**：将通用逻辑（如技能强化）抽为独立 yaml，用 `include_flow` 组合，自动检测循环引用。
